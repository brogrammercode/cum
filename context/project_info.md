# Project Overview: Cum

## Vision
**Cum** is a super lightweight application designed for gamers to stay connected with their community seamlessly. The focus is on minimal resource usage while providing essential social features for gaming.

## Key Features

### 1. Smart Activity Notifications
- **Status Sync**: Automatically notifies friends, followers, and following when a user launches a game application.
- **Granular Control**: Users can customize who receives notifications (Friends, Followers, or Following) based on their personal privacy settings.
- **Efficiency**: Optimized background processes to ensure no performance degradation during gameplay.

### 2. Integrated Voice Communication
- **Voice Channels**: Seamless connection to voice channels with multiple concurrent users.
- **Overlay/Parallel Operation**: Built to function smoothly alongside third-party games.
- **High Performance**: Low-latency audio processing for real-time coordination.

## Technical Goals
- **Super Lightweight**: Maintain a minimal memory and CPU footprint.
- **User Privacy**: Empower users with fine-tuned settings for their online visibility.
- **Connectivity**: Reliable real-time notifications and voice streams.
